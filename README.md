# パンパース最安値チェッカー

パンパース（さらさらケア / はじめての肌へのいちばん）の、タイプ（テープ / パンツ）×サイズごとの最安値を、送料込みの1枚あたり価格で比較できるページです。

- 価格は6時間ごとに自動で調べ直され、このページに自動反映されます
- パンツMは「はいはい（5〜10kg）」「たっち（6〜12kg）」の2種類を分けて表示します
- 1日の使用枚数から「最安パックで何日もつか」「1か月の目安コスト」を計算するツール付きです

## 仕組み

- `index.html` … ページ本体（このファイル1つで完結）
- `data.json` … 価格データ。ページは表示時にこのファイルを読み込んで描画します
- `publish.sh` … 価格リサーチ側の最新データ（`state.json`）を `data.json` にコピーし、差分があれば commit / push するスクリプト。データの差し替えだけでページが更新されるため、価格調査のたびにページ本体を触る必要はありません

送料は神奈川県宛ての条件で確認しています。送料が確認できなかった商品は「送料未確認」と明記し、商品代金のみの1枚あたり価格を表示しています。
